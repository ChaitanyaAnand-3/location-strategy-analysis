# location-strategy-analysis
This project analyse hiring performance, location strategy effectiveness, and workforce distribution for a corporate talent acquisition team. The dashboard provides a comprehensive view of Preferred vs. Non-Preferred market hiring, telecommuter position fulfilment, and time-to-fill metrics across different CBSAs (Core-Based Statistical Areas).

This project is built using SQL Server (SSMS), Power Query, and Power BI. The dashboard provides insights into workforce distribution, hiring performance, CBSA status trends, and telecommuter fulfillment. All data used in the dashboard was extracted from SQL Server using optimized joins, views, and stored procedures. The SQL layer includes INNER JOIN and LEFT JOIN operations across HR, CBSA, and telecommuter tables, along with reusable Views and automated Stored Procedures that support scheduled data refresh. Power Query was used for ETL tasks such as cleaning data, validating data types, handling null values, removing duplicates, and merging multiple datasets to prepare a clean model.

The data model inside Power BI follows a star schema with dimension tables like Date, CBSA, Market, HR Division, and Salary Band, and fact tables like Hiring Plan, Fulfillment, Time-to-Fill, and Population. Relationships were created using one-to-many modeling, and DAX measures were developed for KPIs such as Preferred Current Month, Non-Preferred Current Month, and the Planned CBSA percentage. These calculations help summarize hiring trends and workforce patterns across time.

The dashboard includes multiple visualizations, such as Time to Fill by CBSA Status, Percentage of Total Population by CBSA Status, Telecommuter Positions Compared with Fulfillment, and Telecommuter Plan vs. Filled by Month. These visuals help HR and workforce strategy teams monitor staffing performance, identify hiring gaps, and evaluate how well telecommuter roles are being fulfilled compared to the planned numbers. The project aims to deliver actionable insights for improving hiring efficiency and supporting data-driven decisions across markets and business units.
